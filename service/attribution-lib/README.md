# NVIDIA Attribution Library

This package contains the rules engine used by the NVIDIA Attribution Service.
It is bundled as a local dependency of the Service and is not normally run
directly by end users.

Changes to the bundled rules can be proposed through the
[contribution workflow](../../CONTRIBUTING.md). The Library does not offer a
stable external interface. See [SUPPORT.md](../../SUPPORT.md) for upstream support
and reproduction requirements.
